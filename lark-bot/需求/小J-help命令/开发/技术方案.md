# help 命令 技术方案

## 改动点
仅改 `bot.py` 一处：在 `process_event()` 的群聊分支中，`extract_text()` 之后、`call_ai()` 之前，插入 help 关键词拦截。

## 数据流

```mermaid
flowchart LR
    A[@bot help] --> B{匹配 help/帮助?}
    B -->|是| C[直接返回固定文本]
    B -->|否| D[走 AI 流程]
```

## 关键实现
- 匹配逻辑：`text.strip().lower() in ("help", "帮助")`
- 固定文本直接 `reply_in_chat()`，不调 AI
- 插入位置：bot.py 第 358 行之后

## 依赖与风险
- 无新依赖
- 风险：无，只加了一个提前 return 的分支
