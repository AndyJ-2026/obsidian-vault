# help 命令 规格

## 功能描述
用户在群聊中 @小J 发送包含 "help" 或 "帮助" 的消息时，小J 返回功能列表。

## 输入
- 群聊消息，文本包含 "help" 或 "帮助"（不区分大小写）

## 输出
回复一条功能列表：

```
小J 能做这些事：

📅 约会议 — @我 说"帮我约个会"
❌ 取消会议 — @我 说"取消那个会议"
🔍 查人 — @我 说"查一下 xxx"
📋 消息汇总 — @我 说"汇总一下"（汇总近 2 天与 Jake 相关的消息）
💬 闲聊 — @我 随便说点什么

📊 每天 20:00 自动私信 Jake 工作日报
```

## 约束
- 在 AI 调用之前拦截，不走 MiniMax，直接返回固定文本
- 不影响现有功能

## 验收标准
- [ ] 群里 @小J help → 返回功能列表
- [ ] 群里 @小J 帮助 → 返回功能列表
- [ ] 群里 @小J 其他消息 → 正常走 AI 流程，不受影响
