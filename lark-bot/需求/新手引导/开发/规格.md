# 规格

## 整体流程

```
用户 clone 仓库 → 配置飞书 App → 启动 bot
  ↓
Bot 收到第一条私聊消息
  ↓
检测到没有 config.json → 进入首次配置流程
  → "你想叫我什么名字？"
  → "你叫什么？"（或自动从发送者信息获取）
  → 自动生成 config.json
  → 发送「快速开始」卡片
  ↓
后续使用
  → 新用户首次私聊 → 自动发快速开始卡片（仅一次）
  → "帮助"/"help"/"你能做什么" → 再次发快速开始卡片
```

## 模块拆分

### 模块 0：配置文件 + 去硬编码

**目标**：把所有硬编码的个人信息提取到 `config.json`，clone 后改配置就能用

**config.json**：
```json
{
  "bot_name": "小J",
  "owner_name": "Jake R",
  "owner_open_id": "ou_19af5476f7712283c2bc5f6554d4818b",
  "llm_base_url": "https://api.minimaxi.com/v1",
  "llm_api_key_env": "MINIMAX_API_KEY",
  "llm_model": "MiniMax-M2.5"
}
```

**代码改动**：
- 移除 `JAKE_OPEN_ID` 硬编码，改为读 `config.json`
- prompt 中 "Jake R" → `{owner_name}`，"小J" → `{bot_name}`
- `is_jake` 判断改为 `is_owner`（对比 `config.owner_open_id`）
- 仓库提供 `config.example.json` 作为模板，`.gitignore` 忽略 `config.json`

**首次配置流程**：
```
Bot 启动，发现没有 config.json
  → 第一个私聊 Bot 的人被视为 owner
  → Bot 问："你想叫我什么名字？"
  → 用户回答（如"小助手"）
  → Bot 通过 sender_id 自动获取用户姓名
  → 自动写入 config.json
  → 回复："配置完成！我叫小助手，{owner_name} 你好~"
  → 接着发送快速开始卡片
```

### 模块 1：新用户检测

**触发条件**：Bot 收到 p2p 消息，sender_id 不在已引导用户列表中
**前提**：config.json 已存在（否则先走模块 0）
**行为**：
- 发送快速开始卡片
- 将 sender_id 写入 `onboarded_users.json`，不再重复触发
**存储**：`onboarded_users.json`（与 reminders.json 同级）
```json
{
  "users": ["ou_xxx", "ou_yyy"],
  "last_updated": "2026-05-08"
}
```

### 模块 2：快速开始卡片

**卡片内容**（使用 config 中的变量）：

```
👋 你好！我是{bot_name}，{owner_name} 的飞书 AI 助手

以下是我能做的事：

✅ 闲聊对话 — 直接跟我说话就行
✅ 约会议 — "帮我约个会"
✅ 取消会议 — "取消那个会议"
✅ 查同事 — "查一下 xxx"
✅ 设提醒 — "明天中午提醒我写周报"
⚠️ 消息汇总 — "汇总一下"（需把我拉进群）
⚠️ 定向分析 — "帮我看看 XX 提了什么"（需把我拉进群）
🎙️ 会议转写 — "帮我转写"（需本机运行 Bot）

我已加入的群：
• 群名A
• 群名B
（没有你需要的群？把我拉进去就行）

💡 随时跟我说「帮助」可以再看这张表
```

**卡片格式**：`msg_type: interactive`，用 markdown 元素渲染

### 模块 3：帮助命令更新

**触发词**：`help` / `帮助` / `你能做什么` / `你会什么`
**行为**：发送与模块 2 相同的快速开始卡片（含最新群列表）
**适用范围**：p2p 私聊 + 群聊 @bot
**替换现有**：当前 help 是纯文本，改为卡片

### 模块 4：群列表获取

**实现**：调用 `lark-cli im chats list --as bot` 获取 Bot 已加入的群
**展示**：提取群名，列表显示在卡片底部
**缓存**：每次发卡片时实时拉取（群列表会变动，不缓存）

## 权限模型

| 功能 | 谁能用 | 判断方式 |
|------|--------|---------|
| 闲聊、查人、帮助 | 所有人 | 无限制 |
| 约会议、取消会议、设提醒 | 所有人 | 无限制 |
| 消息汇总、定向分析 | 所有人（在群里 @bot） | 需 Bot 在群内 |
| 会议转写 | 仅 owner | `sender_id == config.owner_open_id` |
| 首次配置 | 仅第一个私聊的人 | 自动成为 owner |
| 日报 | 仅 owner | 私信发给 owner |
