# 技术方案

## 改动

### 1. start-local.sh → 改为操作 LaunchAgent

不再直接 `python3 bot.py &`，改为：
```bash
launchctl unload ~/Library/LaunchAgents/com.jaker.lark-bot.plist
sleep 1
launchctl load ~/Library/LaunchAgents/com.jaker.lark-bot.plist
```

### 2. LaunchAgent plist → bot.py 自己读 .env

plist 中去掉硬编码的 secrets，改为只设 PATH。
bot.py 启动时自己从 .env 加载环境变量。

### 3. bot.py → 启动时加载 .env

在 main() 开头加 dotenv 加载（纯 Python，不加依赖）。

### 4. 保留进程锁作为兜底

`_acquire_lock()` 保持不变，万一有其他方式启动也能防重复。
