# 规格

## 问题

- LaunchAgent `KeepAlive: true` + `start-local.sh` 两套机制冲突
- 手动重启时 pkill 杀进程 → LaunchAgent 立刻拉起新的 → 多实例
- bot.py 进程锁只防 bot.py 重复，但 LaunchAgent 不停重试

## 方案

统一由 LaunchAgent 管理进程生命周期，`start-local.sh` 改为操作 LaunchAgent 而非直接启动进程。

### 行为定义

| 场景 | 行为 |
|------|------|
| 开机 | LaunchAgent 自动启动 bot.py |
| bot.py 崩溃 | LaunchAgent 自动重启 |
| 手动重启 | `start-local.sh` → unload + load LaunchAgent |
| 手动停止 | `launchctl unload` |

### 约束

- 任何时刻只有一个 bot.py 进程
- bot.py 内的进程锁作为兜底保护
- LaunchAgent plist 不再硬编码 secrets（从 .env 读取）
