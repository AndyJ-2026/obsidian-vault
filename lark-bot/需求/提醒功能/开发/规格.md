# 提醒功能 规格

## 模块一：remind action

### 功能描述
用户对 bot 说"X 时间提醒我 Y"，AI 解析出时间和内容，保存到 reminders.json。

### 输入/输出
- REPLY_PROMPT 新增 action：
  - `remind` → params: `time`(ISO8601+08:00), `message`(提醒内容)
- AI 负责把自然语言时间转成 ISO8601（跟约会议一样的逻辑）
- 示例：
  - "明天中午提醒我写周报" → `{time: "2026-05-09T12:00:00+08:00", message: "写周报"}`
  - "下午3点提醒我开会" → `{time: "2026-05-08T15:00:00+08:00", message: "开会"}`

### reminders.json 格式
```json
[
  {
    "time": "2026-05-09T12:00:00+08:00",
    "message": "写周报模板",
    "chat_id": "oc_xxx",
    "sender_id": "ou_xxx",
    "created": "2026-05-08T21:00:00+08:00"
  }
]
```

### 约束与边界条件
- 群里设的提醒发回群里，私聊设的提醒发私聊
- 设置成功后回复用户确认（如"好的，明天中午12:00提醒你写周报~"）
- 时间必须是未来，过去的时间拒绝并提示

### 验收标准
- [ ] "@bot 明天中午提醒我写周报" → 保存到 reminders.json，回复确认
- [ ] 私聊 "下午3点提醒我开会" → 同样保存，回复确认

## 模块二：scheduler 扩展

### 功能描述
现有 scheduler 每 30 秒轮询，扩展它检查 reminders.json，到时间就发消息。

### 逻辑
1. 每 30 秒读 reminders.json
2. 遍历所有提醒，比对当前时间
3. 到时间的 → 发消息到对应 chat_id（纯脚本，不耗 token）
4. 发完从 reminders.json 删除
5. 消息格式："⏰ 提醒：{message}"

### 约束与边界条件
- bot 重启后从 reminders.json 恢复，不丢提醒
- 合上电脑 bot 停止，重新打开后补发已过期的提醒（过期不超过 24 小时的才补发，超过的丢弃）
- reminders.json 不存在时自动创建空数组

### 验收标准
- [ ] 设置提醒后到时间自动发消息
- [ ] bot 重启后提醒不丢失
- [ ] 过期不超过 24 小时的提醒启动时补发
