# 规格

## setup.sh 执行流程

```
./setup.sh
  1. 检查 macOS 版本（≥12.3，ScreenCaptureKit 要求）
  2. 检查/安装 Xcode CLI Tools
  3. 检查/安装 Homebrew
  4. 检查/安装 Node.js（brew install node）
  5. 检查/安装 lark-cli@1.0.0（npm install -g @larksuite/cli@1.0.0）
     - 如已安装新版 → 降级到 1.0.0
  6. 检查/安装 Python 3.12（brew install python@3.12）
  7. 创建 Python venv + 安装依赖（funasr, torch, etc.）
  8. clone meeting-cli + 编译 audio_capture（swiftc）
  9. 输出结果清单 + 提示运行 ./start-local.sh
```

## 每步的检测逻辑

| 步骤 | 检测方式 | 已有 → | 没有 → |
|------|---------|--------|--------|
| macOS | `sw_vers` | 继续 | 报错退出 |
| Xcode CLI | `xcode-select -p` | 跳过 | `xcode-select --install` |
| Homebrew | `which brew` | 跳过 | 自动安装 |
| Node.js | `which node` | 跳过 | `brew install node` |
| lark-cli | `lark-cli --version` | 检查版本 | `npm install -g @larksuite/cli@1.0.0` |
| Python 3.12 | `python3.12 --version` | 跳过 | `brew install python@3.12` |
| venv | `.venv/bin/python` | 跳过 | 创建 + pip install |
| audio_capture | `./audio_capture` 存在 | 跳过 | clone meeting-cli + swiftc 编译 |

## 注意事项

- 仅支持 macOS
- lark-cli 锁定 1.0.0，新版不兼容海外版
- Xcode CLI Tools 安装需要用户手动确认弹窗
- 首次运行 ASR 模型会下载 ~800MB
- audio_capture 编译需要 ScreenCaptureKit 框架（macOS 12.3+）
