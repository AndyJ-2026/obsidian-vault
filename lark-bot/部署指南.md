# 部署指南

## 本地部署

### 环境依赖

```bash
npm install -g @larksuite/cli@latest   # lark-cli
pip3 install lark-oapi openai          # Python 依赖
```

### 配置 lark-cli

交互式配置（推荐，secret 自动存入 Keychain）：

```bash
lark-cli config init
```

或非交互式：

```bash
printf '%s' '你的APP_SECRET' | lark-cli config init \
  --app-id cli_a97a30b1a70a9db9 \
  --app-secret-stdin \
  --brand lark
```

验证：`lark-cli config show` 应显示 appId 和 `****`。

### 启动

```bash
cd ~/lark-bot
./start-local.sh
```

### 停止

```bash
pkill -f "lark-cli event"
pkill -f "python3.*bot"
```

### 查看日志

```bash
tail -f ~/lark-bot/bot.log    # 运行日志
tail -f ~/lark-bot/bot.err    # 错误日志
```

### launchd 自启动（可选）

plist 路径：`~/Library/LaunchAgents/com.jaker.lark-bot.plist`

需要在 plist EnvironmentVariables 里设置：
- `PATH` — 包含 `/usr/local/bin`（lark-cli 所在）
- `LARK_APP_ID`
- `LARK_APP_SECRET`
- `MINIMAX_API_KEY`

注意：launchd 的 KeepAlive 会在崩溃时自动重启，可能产生多个 lark-cli 进程导致重复回复。启动前先确认无残留进程。

```bash
launchctl load ~/Library/LaunchAgents/com.jaker.lark-bot.plist     # 启动
launchctl unload ~/Library/LaunchAgents/com.jaker.lark-bot.plist   # 停止
```

## 云端部署（待实现）

### 方案对比

| 方案 | 费用 | WebSocket 支持 | 问题 |
|------|------|----------------|------|
| Railway | $5 试用额度 | 支持 | 容器无 Keychain |
| Fly.io | 需绑信用卡 | 支持 | 同上 |
| Render | 免费 | 休眠断连 | 不适合长连接 |
| Cloudflare Workers | 免费 | 不支持 | 无状态 serverless |

### 核心阻塞：容器无 Keychain

lark-cli 把 App Secret 存在 OS Keychain。Docker 容器没有 Keychain，导致 `config init` 写入成功但读取失败。

尝试过但失败的方案：
- 直接写 config.json 明文 → lark-cli 不认
- 装 gnome-keyring + dbus → 容器里 daemon 起不来

### 解决方向：Python SDK 替代 lark-cli

用 `lark_oapi` Python SDK 直接做 WebSocket 订阅和 API 调用，绕开 lark-cli 和 Keychain：

```python
import lark_oapi.ws as ws

handler = lark.EventDispatcherHandler.builder("", "") \
    .register_p2_im_message_receive_v1(on_message) \
    .build()

client = ws.Client(app_id, app_secret,
    event_handler=handler,
    domain="https://open.larksuite.com")
client.start()
```

改造后 Dockerfile 可简化为纯 Python：

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python3", "-u", "bot.py"]
```

## 凭证安全

- App Secret 存在 macOS Keychain，由 lark-cli 管理
- **禁止**用 `security delete-generic-password` 删除 lark-cli 相关 Keychain 条目
- **禁止**用错误值覆盖 Keychain（`config init` 会覆盖已有配置）
- `.zshrc` 中的 `LARK_APP_SECRET` 环境变量可能是旧值，不一定准确
- 如需重新配置，用交互式 `lark-cli config init` 从开发者后台复制正确 secret
