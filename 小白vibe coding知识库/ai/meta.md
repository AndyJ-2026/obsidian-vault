# 项目定位与目录结构

## 定位
「小白 vibe coding 知识库」是面向零代码基础用户的 AI 编程方法论库。
包含两类内容：
1. 面向人的指南（入门、核心概念、快速上手、实战场景）
2. 面向 AI 的工作约定（ai/ 目录 + 需求模板）

## 本库目录结构
```
小白vibe coding知识库/
├── CLAUDE.md          ← 本库 AI 行为准则
├── ai/                ← 子模块（工作流、仓库、frontmatter 等）
├── 入门指南.md        ← 什么是 vibe coding
├── 核心概念.md        ← 五个核心概念（大白话）
├── 快速上手.md        ← 从打开终端到交付
├── 实战场景.md        ← 典型使用场景
└── 需求/_模板/        ← 新需求模板（与根目录 需求/_模板/ 相同）
```

## 与 Obsidian Vault 整体的关系
本库是 Vault 根目录下的一个子知识库。整体结构参考根目录 CLAUDE.md。

## 命名约定
- 需求文件夹：简短中文名（如 `飞书签到机器人`）
- 模块名：与代码模块对应的简称
- 文件名：固定名（index.md, 规格.md, 技术方案.md, 任务清单.md）
