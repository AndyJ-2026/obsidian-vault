# Vibe Coding 入门指南

## 什么是 Vibe Coding

一句话：**你说想要什么，AI 帮你写代码。**

你不需要会编程。你只需要能把自己的想法说清楚——用中文、用大白话——AI 就能帮你把想法变成可运行的程序。

但"说清楚"这件事本身就是一门技术。这套工作流就是帮你把想法一步步变清晰的方法。

## 这套工作流解决什么问题

直接跟 AI 说"帮我做个 XX"，最常遇到的问题：

| 问题 | 原因 | 这套工作流怎么解决 |
|------|------|-------------------|
| AI 做的不是我想要的 | 你心里的想法没说全，AI 自己脑补了 | 先用「规格」把要什么写清楚，对齐了再动手 |
| 改了半天越改越乱 | 一次想做太多，AI 记不住上下文 | 拆成小块，一块一块做 |
| 聊着聊着 AI 忘了前面说的 | 对话太长，早期信息被挤掉了 | 关键信息写在文件里，不靠对话记忆 |
| 下次接着做不知道做到哪了 | 进度全在聊天记录里，找不到 | 进度记在知识库里，随时可查 |

## 你需要准备什么

1. **Obsidian**（免费）— 一个本地笔记软件，用来管理你的需求和文档
2. **Claude Code**（付费）— AI 编程助手，在终端里运行
3. **GitHub 账号**（免费）— 代码存放的地方

安装好之后，打开终端，进入你 clone 下来的知识库目录，启动 Claude Code：
```
cd <你的知识库路径>
claude
```

然后你就可以开始跟 AI 对话了。

## 两个核心命令

### `/start <需求名>` — 启动一个新需求
```
/start 飞书签到机器人
```
AI 会帮你建好文件夹、问你几个问题，然后引导你开始梳理需求。

### `/dev <你想做什么>` — 直接开干
```
/dev 我想做一个每天早上 9 点自动发天气预报到飞书群的机器人
```
AI 全程包办：理解你的想法 → 确认 → 设计 → 写代码 → 测试 → 交付。
