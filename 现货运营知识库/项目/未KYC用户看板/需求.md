# 未KYC用户转化与资金流失监控看板 — Brief

## 一、需求背景
监控未KYC用户的真实价值与流失风险，为促KYC策略提供数据支撑。

## 二、全局筛选维度
- 时间范围：自然日/周/月（默认近30天）
- 用户注册时间：支持同期群分析
- 国家/地区
- 资产统一折算为 USDT

## 三、核心指标口径
- **目标人群**：注册成功，当前KYC等级 < 基础交易等级的用户
- **KYC转化率**：周期内完成KYC人数 / 周期初未KYC总数
- **净入金**：总入金（链上充值+法币入金+C2C买入）- 总出金（链上提现+法币出金+C2C卖出），剔除内部转账
- **AUM**：每日0:00 UTC快照，∑(持仓数量 × 当日收盘价)
- **资金流失率**：周期内提现离场资金 / 周期初总资产

## 四、看板模块

### 模块1：核心数据卡片
- 未KYC用户总数（环比）
- 未KYC用户总资产（USDT）
- 本期净入金（红绿双色）
- 本期KYC转化率

### 模块2：净入金与资产存量监控
- **图表A**：净入金趋势（堆叠柱状图+折线图，出金负轴展示）
- **图表B**：AUM趋势（折线图，后续可叠加BTC价格参考线）
- **图表C**：流失资金币种分布（饼图，Top币种占比）

### 模块3：KYC转化漏斗
- 每日触发KYC人数 vs 通过KYC人数（双折线图）

### 模块4：高价值用户明细表
- 字段：UID、注册时间、余额、最后活跃时间、最后入金时间
- 按余额降序，敏感信息脱敏

## 五、数据口径备注
- AUM使用每日0:00 UTC收盘价折算
- 净入金剔除平台内部转账
- AUM变动 = 净入金 + 币价波动，需区分归因
