# 跨部门协同SOP — Brief

## 目标
建立以现货运营发起的极速响应协同机制。

## 协同角色与职责

| 角色 | 职责 |
|------|------|
| 现货业务（发起） | 监测事件→触发剧本→圈定资产与利益点 |
| 合约业务（联动） | 同步开启同资产合约赛 |
| 合规（前置） | 极速审单，严守红线，确保0事故 |
| 市场（站外放大） | PR、社群、KOL矩阵造势引流 |
| 中台（站内承接） | 弹窗/Banner/站内信/邮件，唤醒存量 |

## 待决事项
- 合规审单最长耗时（SLA）
- 中台资源位配置时效
- 市场宣发标准化流程与Timeline
- 活动前端模板复用能力评估
