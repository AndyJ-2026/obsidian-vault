## 利弊写作范例（方案2，被选中方案）

### 利
```
①踩spacex S-1招股书公开披露窗口（5/15-22）：IPO消息与认购期天然重叠，消息面二次催化；
②节奏更合理：5/11预热页先行，承接当前涨13%热度，给用户7天认知窗口；
③破发风险较低：越往临近IPO价格越高，财富效应越强
```

### 弊
```
①热度衰减：5/10-15为消息空窗期，当前热度自然衰减；
②S-1延迟披露: 若S-1延迟披露消息催化落空；
```

## 写作特征总结

1. **利弊格式**：`①关键词：` + 一句话解释，结尾加 `；`
2. **条数**：每个方案利弊各 2-3 条，宁少勿多
3. **业务语言**：不堆技术数据，写业务结论
4. **不确定性**：用"有可能"等词标注不确定结果
5. **真实影响**：每条弊都是能改变决策的实质风险
