# 三板斧 Skill 开发

## 目标
Claude Code slash command `/sanbanfu`，输入命题+选项 → AI 分析利弊 → 预览 → 发布到飞书文档。

## 产出
- `.claude/commands/sanbanfu.md` — 已完成 ✅

## 规格要点（v2，已通过）
详见 `开发/规格.md`（保留作为规格存档）

核心能力：
1. 信息充分性检查 — 生成利弊前先评估数据是否够
2. 质量标准 — 命题锐利、选项MECE、背景带数据、利弊直指决策、弊带解法
3. 利弊标注来源 — [数据]/[推断]/[行业]
4. Challenge 模式 — 质疑遗漏选项、数据缺口、表述优化
5. 两步输出 — 终端预览（带标注）→ 飞书发布（不带标注）
