## 核心规则

1. **先读再做**：进入任何项目前，先读 入口.md 确认类型和背景
2. **缺口暴露**：按项目类型检查必选文件，缺了就提示，不默默跳过
3. **产出入库**：产出写入飞书文档，飞书链接回填 需求.md
4. **会话隔离**：当用户开始一个与当前会话明显不同的任务时，主动提示开新窗口，并给出可直接复制的命令：
   ```bash
   tmux new -s <任务名> -c ~/Documents/Obsidian\ Vault/现货运营知识库 && claude
   ```
