# 现货运营知识库 FAQ

## 这是什么？

一个用 Obsidian + Claude Code 搭建的 AI 协作知识库。你在本地写需求，AI 帮你执行调研、写方案、出报告，产出自动写入飞书文档。

## 我需要装什么？

| 工具                                           | 用途       | 安装                                         |
| -------------------------------------------- | -------- | ------------------------------------------ |
| [Obsidian](https://obsidian.md)              | 本地知识库编辑器 | 官网下载                                       |
| [Claude Code](https://claude.ai/claude-code) | AI 协作终端  | `npm install -g @anthropic-ai/claude-code` |
| tmux                                         | 多任务窗口管理  | `brew install tmux`                        |

## 怎么开始？

```bash
# 1. 打开终端，进入知识库目录
cd ~/Documents/Obsidian\ Vault/现货运营知识库

# 2. 启动 Claude Code
claude

# 3. 输入 /start 查看当前项目概览
/start
```

## 项目分两类？

| 类型      | 适用场景     | 必选文件                  | 举例                 |
| ------- | -------- | --------------------- | ------------------ |
| **标准化** | 可重复执行的流程 | 入口.md + 规范.md + 需求.md | 竞品调研（每次换个主题跑同一套流程） |
| **非标**  | 一次性任务    | 入口.md + 需求.md         | 看板需求、活动方案          |

## 怎么新建一个项目？

直接告诉 AI：

> "帮我建一个新项目，名字叫 XX，目标是 XX"

AI 会自动创建目录和入口文件。你也可以手动建：

```
项目/我的项目/
├── 入口.md      ← 写上 type: 标准化 或 非标
└── 需求.md      ← 写清楚要做什么
```

## 入口.md 怎么写？

```yaml
---
type: 标准化
status: 进行中
owner: 你的名字
created: 2026-04-14
---

# 项目名称

## 背景
为什么要做这个项目

## 核心目标
- 目标1
- 目标2
```

## 产出去哪了？

AI 执行完后会把产出写入本地文件（如 `产出.md`）。你手动复制到飞书后，把飞书链接回填到 需求.md 的 frontmatter 里。

你在 需求.md 的 frontmatter 里能看到 `lark: https://...` 就是产出链接。

## 为什么要用 tmux？

每个任务在独立窗口运行，避免 AI 上下文混乱。常用操作：

| 想做什么 | 命令 |
|----------|------|
| 开新任务窗口 | `tmux new -s 任务名` → `claude` |
| 暂时离开 | `Ctrl+b` 松开后按 `d` |
| 回到之前的窗口 | `tmux a -t 任务名` |
| 看有哪些窗口 | `tmux ls` |
| 关掉窗口 | `tmux kill-session -t 任务名` |

不用 tmux 也能跑，只是同时做多个任务时会互相干扰。

## AI 能帮我做什么？

- **竞品调研**：给主题，AI 按规范多轮搜索 + 截图 + 出对比报告
- **新项目启动**：给项目名和目标，AI 建目录 + 写需求草稿
- **推进现有项目**：说项目名，AI 自动检查缺什么文件，从断点继续
- **活动方案**：基于调研结论，产出方案文档
- **飞书读取**：读取飞书上的参考文档作为调研输入

## AI 会自动检查什么？

进入项目时 AI 会检查必选文件是否齐全：

- 缺 入口.md → 提示先建
- 缺 规范.md（标准化项目）→ 问你要不要补
- 缺 需求.md → 提示先确认需求

缺什么报什么，不会偷偷跳过。

## 我想改规则怎么办？

知识库的 AI 行为规则在这几个文件里：

| 文件 | 管什么 |
|------|--------|
| `CLAUDE.md` | 核心规则（AI 每次启动都会读） |
| `ai/定位.md` | 项目分类和目录结构 |
| `ai/工作流.md` | 进入检查、版本追踪 |
| `ai/格式约定.md` | frontmatter 字段规范 |
| `ai/工具.md` | 外部工具配置记录 |

直接改文件内容，下次对话 AI 就会按新规则执行。

## 常见问题

**Q: AI 说"该项目缺执行规范"怎么办？**
A: 标准化项目需要一个 规范.md 告诉 AI 怎么执行。可以让 AI 帮你写一个初版。

**Q: 飞书文档链接在哪看？**
A: 在对应的 需求.md 文件顶部的 frontmatter 里，`lark:` 字段。

**Q: 能不能多人同时用？**
A: 可以。每个人在自己的终端开 Claude Code 会话，操作各自的项目。但注意不要同时编辑同一个文件。

**Q: AI 跑到一半断了怎么办？**
A: 重新进入对话，告诉 AI 项目名，它会读 入口.md 自动恢复上下文，从断点继续。
