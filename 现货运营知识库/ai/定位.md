# 项目定位

现货运营团队知识库（Obsidian vault），文档驱动运营。

知识库管结构（需求、规范），产出写入本地，用户手动同步到飞书。

# 项目分类

## 标准化项目

可重复执行的流程型工作（如竞品调研），同一套规范反复跑不同主题。

```
项目/<项目名>/
├── 入口.md          ← 必选｜项目背景、范围，type: 标准化
├── 规范.md          ← 必选｜AI 执行规范（怎么采、怎么做）
└── <主题或批次>/
    └── 需求.md      ← 必选｜主题、范围、时间；完成后 frontmatter 记录飞书链接
```

## 非标项目

一次性任务或策略设计（如看板需求、活动方案），结构灵活。

```
项目/<项目名>/
├── 入口.md          ← 必选｜项目背景，type: 非标
└── <模块>/
    └── 需求.md      ← 必选｜需求、目标、方案（合一）；完成后 frontmatter 记录飞书链接
```

# 其他目录

```
素材库/              ← 高转化话术、活动模板
复盘/                ← 活动复盘沉淀
ai/                  ← CLAUDE.md 模块化拆分
```
