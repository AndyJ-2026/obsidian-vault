## 飞书 CLI（lark-cli）— 官方版

飞书官方 CLI，支持读取和创建云文档、上传图片、搜索等。

- **仓库**：https://github.com/larksuite/cli
- **版本**：1.0.11
- **安装方式**：`npm install -g @larksuite/cli`
- **二进制位置**：`/usr/local/bin/lark-cli`
- **配置文件**：`~/.lark-cli/config.json`
- **Brand**：`feishu`
- **App ID**：`cli_a9561f52053d9bc0`
- **环境变量**：
  - `LARK_APP_SECRET`：已写入 `~/.zshrc` 和 `~/.claude/settings.json`
- **已授权 Scope**：全量开通（docx 读写创建、drive 上传下载、wiki、sheets、calendar、im、mail、minutes 等）
- **用法示例**：
  ```bash
  # 读取文档
  lark-cli docs +fetch --doc-id "<文档ID>"
  # 创建文档
  lark-cli docs +create --title "标题" --markdown "内容"
  # 文档ID 取自飞书链接最后一段，如 MrrrwCTlRiJFaCkhsrIcR86Enwe
  ```

## Jina Reader

免费网页内容提取，无需安装，直接在 URL 前加前缀使用。

- **用法**：`https://r.jina.ai/<目标URL>`
- **适用场景**：交易所公告中心、静态内容页
- **局限**：无法处理纯 JS 渲染的活动列表页

## web-access Skill

AI Agent 联网增强 Skill，通过 CDP 直连用户 Chrome，天然携带登录态。替代 Firecrawl MCP（免费额度已用完）。

- **仓库**：https://github.com/eze-is/web-access
- **安装方式**：`npx skills add eze-is/web-access`
- **安装位置**：`~/.claude/skills/web-access`（symlink 到本库 `.agents/skills/web-access`）
- **作用范围**：全局（所有 Claude Code 项目可用）
- **前置要求**：
  - Node.js 22+
  - Chrome 开启远程调试：`chrome://inspect/#remote-debugging`
- **核心能力**：
  - 联网工具自动选择（WebSearch / WebFetch / curl / Jina / CDP 按场景调度）
  - CDP 浏览器操作（直连已登录 Chrome，带登录态访问受保护页面）
  - Chrome 书签/历史检索
  - 站点经验存储（按域名积累，跨 session 复用）
- **主要用途**：
  - 竞品调研（搜索 + 抓取公开/登录态页面）
  - 访问内部系统后台
  - 处理 JS 渲染的动态页面（替代 Firecrawl）
- **局限**：
  - 登录态仅限 Chrome 已有的，不能突破未登录站点
  - 无代理池，不擅长对抗强反爬
  - 社交平台自动化有封号风险
