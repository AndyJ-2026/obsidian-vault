## 👋 欢迎使用现货运营知识库

这是一个 Obsidian + Claude Code 搭建的 AI 协作知识库。你写需求，AI 帮你执行调研、写方案、出报告。

### 工作流程

```
写需求 → AI 执行 → 审阅产出 → 复制到飞书
```

### 项目分两类

- **标准化项目**：可重复跑的流程（如竞品调研），有统一规范
- **非标项目**：一次性任务（如看板需求、活动方案）

### 现在你可以

| 想做什么 | 怎么说 |
|----------|--------|
| 看看有哪些项目 | `/start` |
| 做一个竞品调研 | 直接说主题，如"调研一下 XX 活动" |
| 建一个新项目 | "帮我建一个项目，名字叫 XX，目标是 XX" |
| 继续之前的项目 | 说项目名，AI 自动恢复上下文 |

### 更多问题

查看 FAQ.md 了解完整使用说明，包括 tmux 多任务、规则修改等。
