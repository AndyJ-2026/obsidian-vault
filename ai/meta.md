# 项目定位与目录结构

## 定位
本 Obsidian 库是团队（当前主要为个人）的业务知识中心，承载需求管理、技术调研、方案设计等非代码产出。
代码仓库通过 git worktree 与本库解耦。

## 目录结构
```
Obsidian Vault/
├── CLAUDE.md          ← AI 工作约定入口
├── ai/                ← CLAUDE.md 子模块
├── 需求/              ← 需求管理（每需求一文件夹）
│   ├── _模板/         ← 新需求复制此模板
│   └── <需求名>/
│       ├── index.md
│       ├── 草稿区/
│       ├── 调研/
│       └── 开发/<模块>/
│           ├── 规格.md
│           ├── 技术方案.md
│           └── 任务清单.md
├── 会议纪要/
├── 视频工作流/
└── 现货运营知识库/
```

## 命名约定
- 需求文件夹：简短中文名，无空格用连字符（如 `黑天鹅监控`）
- 模块名：与代码模块对应的简称
- 文件名：固定名（index.md, 规格.md, 技术方案.md, 任务清单.md）
