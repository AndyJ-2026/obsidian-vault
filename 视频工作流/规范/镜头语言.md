# 镜头语言

分镜设计时的镜头语言速查手册 + 美术方法论。

## 景别

**每个景别都有叙事目的，不是随便选的。**

| 景别 | 英文 | 画面范围 | 叙事作用 | 传递什么信息 |
|------|------|----------|----------|-------------|
| 大远景 | Extreme Long Shot | 广阔环境，人物极小 | 建立场景 | 规模感、史诗感、渺小感 |
| 远景 | Long Shot | 完整环境 + 人物全身 | 交代环境 | 强化画面张力，暗示突破或希望 |
| 全景 | Full Shot | 人物全身为主 | 展示人物与环境关系 | 角色在空间中的位置和状态 |
| 中景 | Medium Shot | 人物膝盖以上 | 对话、日常动作 | 传达心理暗示、安全感、稳定感 |
| 近景 | Close-up | 人物胸部以上 | 表情、情绪传达 | 聚焦情绪，让观众感受角色内心 |
| 特写 | Extreme Close-up | 局部细节 | 强调关键元素 | 吸引注意力，制造张力，聚焦核心卖点 |

### 景别切换的叙事逻辑

景别切换不是随机的，要有叙事逻辑：

```
特写（聚焦产品/痛点）→ 中景（传递情绪/暗示）→ 远景（释放/壮观）
= 从细节到全貌的展开

远景（建立场景）→ 中景（进入故事）→ 特写（高潮聚焦）
= 从全貌到细节的推进
```

## 运镜方式

| 运镜 | 英文 | 描述 | 情绪效果 |
|------|------|------|----------|
| 推 | Push in / Dolly in | 镜头向主体靠近 | 聚焦、紧张、强调 |
| 拉 | Pull out / Dolly out | 镜头远离主体 | 揭示全貌、释放张力 |
| 摇 | Pan | 镜头水平旋转 | 环顾、跟随、展示空间 |
| 移 | Track / Dolly | 镜头平行移动 | 跟随运动、流畅过渡 |
| 跟 | Follow | 镜头跟随主体运动 | 沉浸感、紧张追逐 |
| 升 | Crane up / Tilt up | 镜头向上运动 | 揭示、壮观、希望 |
| 降 | Crane down / Tilt down | 镜头向下运动 | 压迫、发现、聚焦 |
| 固定 | Static | 镜头不动 | 稳定、客观、留白 |
| 环绕 | Orbit | 围绕主体旋转 | 展示立体感、聚焦主体 |
| 手持 | Handheld | 轻微晃动 | 真实感、紧张、纪实 |

## 转场类型

| 转场 | 适用场景 | 节奏感 |
|------|----------|--------|
| cut（硬切） | 节奏变化、情绪转折、快节奏段落 | 快 |
| fade（淡入淡出） | 时间流逝、场景平缓过渡 | 慢 |
| slide（推移） | 同一叙事线上的场景推进 | 中 |
| zoom（缩放过渡） | 从概念到细节、聚焦 | 中 |
| wipe（擦除） | 场景大幅变化、风格化过渡 | 中 |
| match cut（匹配剪辑） | 形状/动作/色彩的相似性过渡 | 高级 |
| whip pan（甩镜） | 快速场景切换、能量感 | 快 |

## 节奏控制

| 节奏 | 单镜头时长 | 适用情绪 |
|------|-----------|----------|
| 极快 | 1-2s | 紧张、混乱、高能 |
| 快 | 2-4s | 活力、兴奋、信息密集 |
| 中 | 4-6s | 叙述、展示、日常 |
| 慢 | 6-10s | 沉浸、情感、治愈 |
| 极慢 | 10s+ | 冥想、留白、史诗 |

### 节奏变化模板

```
"燃"视频：慢（铺垫）→ 中（发展）→ 快（高潮密集切换）→ 慢（收尾沉淀）
叙事视频：中（开场）→ 慢（情感段落）→ 中（推进）→ 快（高潮）→ 慢（结局）
产品视频：快（钩子吸引）→ 中（功能展示）→ 慢（价值传递）→ 快（CTA）
```

### 变速处理

同一段 AI 视频，通过变速可以显著提升节奏感：

| 手法 | 效果 | 适用场景 |
|------|------|----------|
| 减速（0.5x-0.8x） | 沉浸感、史诗感 | 关键动作、情绪高潮、风景 |
| 加速（1.2x-2x） | 紧张感、能量感 | 蒙太奇、过渡段、时间流逝 |
| 变速曲线 | 节奏起伏 | 从慢到快的加速、高潮前的减速 |

在人工剪辑阶段处理，是提升成品质感最低成本的手段之一。

## 参考素材

### 静态参考图

每个镜头最多 3 张参考图，分别锚定：

| 维度 | 作用 | 示例来源 |
|------|------|----------|
| 构图 | 画面布局、元素位置、景别 | 电影截帧、摄影作品 |
| 色调 | 色彩氛围、光影、冷暖 | 电影调色截帧、绘画 |
| 氛围 | 情绪感觉、整体气质 | 动漫场景、广告画面 |

### 动态参考（视频参考）

**人物动线、舞蹈、打斗等复杂动作，找真实视频片段做参考比写提示词管用得多。**

视频生成模型支持直接喂入视频参考：
- **动作参考**：一段舞蹈、一个走路姿态、一个武打动作
- **运镜参考**：一段推镜、一个环绕、一个跟拍

搜索方向：

| 动作需求 | 搜索关键词 |
|----------|-----------|
| 走路/跑步 | `walking cinematic`, `running tracking shot` |
| 舞蹈 | `dance choreography reference`, `名场面+舞种` |
| 打斗 | `fight scene reference`, `action choreography` |
| 情绪动作 | `sad walking away`, `excited reaction shot` |
| 运镜 | `dolly zoom example`, `crane shot film`, `tracking shot` |

## 角色一致性

### 三件套

1. **统一人物** — 四视图锚定 + 描述词锁定
2. **统一材质** — 全片使用同一风格参考图（Nano Banana + 风格锚点）
3. **优雅品牌植入** — 品牌元素自然融入画面，不是硬贴 logo

### 四视图（Character Turnaround Sheet）

每个角色在进入分镜前，先生成四视图（正面/侧面/3/4角度/背面，白底，统一光照）作为全片角色锚点。

### 去假人化

AI 生成真人时容易"塑料感"：

**常规提示词**（效果一般）：
> 维持人物统一，脸不变形

**进阶提示词**（效果好）：
> 保持相同的骨骼结构、眼距和下颚几何形状。禁止美化，禁止改变年龄。真实皮肤质感，可见毛孔和微瑕疵。

**工具增强**：Higgsfield — 真人视频去假人化，提升皮肤质感和毛孔细节。

### 一致性策略

1. **四视图锚定** — 所有镜头引用四视图作为参考输入
2. **描述词锁定** — 提示词中复用完全相同的外貌描述
3. **按需选角度** — 根据景别从四视图裁出对应角度
4. **逐镜头校验** — 生成后对比四视图，检查关键特征

## 情感渲染技巧

| 技巧 | 效果 | 示例 |
|------|------|------|
| 微表情 | 传递内心情感 | 抬头向前=对未来的愿景；皱眉=焦虑 |
| 虚实切换 | 增强代入感 | 从虚拟世界切回现实，观众更容易共情 |
| BGM 配合 | 强化情绪 | 有配音时 BGM 让路，纯画面段落 BGM 推情绪 |
| 景别配合 | 控制情感距离 | 特写=亲密/紧张，远景=释放/壮观 |
