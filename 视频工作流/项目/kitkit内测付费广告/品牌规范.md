# KitKit 品牌规范

## 核心视觉隐喻

**摊开的方格笔记本 + 桌面文具**——纸质感、手写风、温暖色调。

## 品牌色

| 名称 | 色值 | 用途 |
|------|------|------|
| paper | `#f7f4ee` | 背景色（温暖米白） |
| ink | `#222222` | 主文字色 |
| blue-pen | `#3a6bc5` | 主交互色、Logo 后半 |
| red-pen | `#c94a4a` | 强调/警告、Logo 前半 |
| green-hl | `#5ba85b` | 成功状态 |
| yellow-hl | `rgba(255,230,100,0.3)` | 高亮 |
| grid-line | `rgba(180,200,230,0.25)` | 方格线 |
| margin-line | `rgba(200,80,80,0.18)` | 左侧红线 |
| tape | `rgba(255,230,100,0.45)` | 胶带装饰 |

## 调性关键词

温暖、手绘、纸质、playful、亲切、不冰冷、像在笔记本上涂鸦

## 画面风格

- 方格纸背景（30px grid）+ 红色 margin line + 装订孔
- 纸质噪点纹理
- rough.js 手绘装饰元素（铅笔、橡皮、尺子、拓扑网络 doodle）
- 胶带、折角、便签卡片
- 不规则圆角边框（歪歪扭扭的手绘感）
- 避免：直角矩形、冰冷科技感、深色主题
