# 项目定位

AI 视频制作工作流。适用于任何品牌、任何产品的视频制作。

核心理念：
- **剧本和分镜是灵魂** — 工作流的重心在创意阶段，不在技术合成
- **参考驱动** — 分镜设计从经典场面中汲取构图和氛围，而非凭空想象
- **逐镜头交付** — 一个 shot 一个 shot 过，不批量生成
- **人机协作** — AI 负责剧本、分镜、提示词；人负责生成工具操作和最终剪辑

# 目录结构

```
视频工作流/
├── CLAUDE.md                ← 入口，引用 ai/ 子模块
├── ai/                      ← Claude 操作手册（通用）
│   ├── 定位.md              ← 项目定位（本文件）
│   ├── 工作流.md            ← 编剧→美术→摄影→后期
│   └── 格式约定.md          ← 目录结构、文件格式、提示词模板、尺寸
├── 规范/                    ← 通用内容标准（不含品牌特定内容）
│   ├── 镜头语言.md          ← 景别、运镜、转场、角色一致性
│   └── 音频规范.md          ← 配音、BGM、音效
└── 项目/                    ← 各视频项目的工作区
    └── <项目名>/
        ├── 分镜.md          ← 项目总控（脚本+分镜）
        ├── 品牌规范.md      ← 该项目的品牌色、视觉风格、logo
        ├── 风格锚点.jpg     ← 全片视觉风格基准
        ├── 产品资料/        ← PRD、截图等（可选）
        └── shot1-<描述>/    ← 每个 shot 的工作目录
```

# 生成工具（人操作）

| 工具 | 用途 |
|------|------|
| **Seedance**（字节） | 视频生成主力，多模态输入 |
| **可灵**（快手） | 首尾帧控制，无缝循环 |
| **即梦 Dreamina** | 图生图、局部重绘、扩图 |
| **Nano Banana** | 风格一致性好的图片生成 |
| **Midjourney** | 角色四视图、高质量图片 |
