# 格式约定

## 项目目录结构

```
项目/<项目名>/
├── 分镜.md              ← 项目总控（故事脚本+分镜总览）
├── 品牌规范.md           ← 该项目的品牌色、视觉风格、logo、调性
├── 风格锚点.jpg          ← 全片视觉风格基准
├── 产品资料/             ← PRD、产品截图等（可选）
├── shot1-<描述>/         ← 每个 shot 的工作目录
├── shot2-<描述>/
└── ...
```

## Shot 文件夹结构

每个 shot 是一个独立工作目录，记录从参考到成品的全过程：

```
项目/<项目名>/shot<N>-<描述>/
├── 参考/                ← 参考图（构图/色调/氛围），用完可删
│   └── 动线参考/        ← 可选：动作/运镜的视频参考片段
├── 提示词.md            ← 图生图 + 图生视频提示词（必须保留）
├── 首帧.jpg             ← 确认的首帧画面
├── 尾帧.jpg             ← 确认的尾帧画面
└── video.mp4            ← 最终视频片段
```

### 文件说明

| 文件 | 必选 | 说明 |
|------|------|------|
| 参考/ | 工作中必选 | 参考图，确认画面后可清理 |
| 参考/动线参考/ | 可选 | 动作姿态或运镜的视频参考（喂给视频生成模型） |
| 提示词.md | 必选 | 结构化提示词记录，方便迭代和复用 |
| 首帧.jpg | 必选 | 确认的首帧，也是上一个 shot 的尾帧 |
| 尾帧.jpg | 必选 | 确认的尾帧，也是下一个 shot 的首帧 |
| video.mp4 | 最终必选 | 用户确认的最终视频片段 |

### 命名规范

- 首帧/尾帧：`首帧.jpg`、`尾帧.jpg`（统一命名，不用时间戳或哈希）
- 视频：`video.mp4`
- 迭代版本：`首帧-v2.jpg`、`video-v2.mp4`

### 连贯性原则

相邻 shot 共享帧：Shot N 的尾帧 = Shot N+1 的首帧。

## 提示词.md 格式

提示词.md 只记录**生成用的提示词和迭代过程**。镜头的创意决策（景别、运镜、情绪、叙事作用）在分镜.md 中记录，不在此重复。

```markdown
---
shot: 1
version: 1
status: 待制作 | 参考确认 | 首帧确认 | 尾帧确认 | 视频确认
---
```

## 提示词编写原则

**唯一定义，工作流.md 和镜头语言.md 均引用此处。**

### 加减法原则

| 场景 | 策略 | 说明 |
|------|------|------|
| 图生图 | **减法** | 参考图已给大量信息，提示词只写"改什么/保留什么/去掉什么" |
| 文生图 | **分层加法** | 风格参数 + 画面主体 + 动作控制，逐层叠加 |
| 局部重绘 | **极简** | 只描述要改的区域 |
| 视频生成 | **动态聚焦** | 参考图管静态，提示词只管运动和变化 |

### 图生图提示词结构

```
风格参数（画面风格/色调/镜头焦距/画质参数）
+ 画面主体（场景/环境/核心元素）
+ 动作控制（人物姿态/穿着/动作状态）
```

### 图生视频提示词结构

```
主体描述（角色相貌细节 + 身体姿态 → 锁角色一致性）
+ 空间视角（第一人称/特写/电影镜头/广角等）
+ 人物表情（面部表情 → 锁情绪一致性）
+ 镜头语言（运镜 + 衔接 + 景深/虚化）
```

### 相机参数增强电影质感

| 参数 | 效果 | 示例 |
|------|------|------|
| 焦距 | 视角和压缩感 | `shot on 85mm lens`，`24mm wide angle` |
| 光圈 | 虚化 | `shallow depth of field, f/1.4` |
| 快门 | 运动模糊 | `motion blur, slow shutter` |
| 胶片 | 色调质感 | `Kodak Portra 400 film grain` |
| 机位 | 视角 | `low angle shot`，`aerial shot` |

### 迭代式精修（"一笔笔画"）

复杂画面不要指望一次到位：
1. 提取/生成底图
2. 更新材质/风格（"将图一渲染成图二的质感"）
3. 多角度/多变体挑选
4. 去除多余元素
5. 元素组合
6. PS 细节精修

## 分镜.md 格式

每个项目一份总分镜，是整个视频的**框架总控**。分镜.md 是所有创意决策的 source of truth，提示词.md 只记录执行层的提示词。

```markdown
---
title: 项目标题
target_duration: 30s
format: 竖版 9:16 | 横版 16:9
version: 1
status: 草稿 | 脚本确认 | 分镜确认 | 制作中 | 完成
created: 2026-04-20
lark:                        # 最终产出上传后回填链接
---

## 策略背景

（目标受众、投放渠道、核心信息、行动号召）

## 故事脚本

（一段连贯的叙事文字，说清楚这个视频在讲什么故事。
不是 shot 列表，是故事本身。）

## 叙事结构

（叙事模板 + 段落划分）

## 情绪曲线

（情绪走向 + 节奏变化）

## 风格锚点

（全片视觉基准：锚点图路径 + 风格描述关键词）

## 角色设定

（如有真人角色：外貌描述、关键特征、四视图路径、锁定描述词）

## 分镜总览

| Shot | 描述 | 情绪 | 景别 | 景别理由 | 运镜 | 转场 | 时长 | 状态 |
|------|------|------|------|----------|------|------|------|------|
| 1 | ... | 紧张 | 近景 | 聚焦表情传递焦躁 | 推 | fade | 4s | 视频确认 |

转场值使用标准类型：cut / fade / slide / zoom / wipe / match cut / whip pan

状态值统一使用：待制作 | 参考确认 | 首帧确认 | 尾帧确认 | 视频确认

## 逐 Shot 详情

### Shot 1 — <描述>

**配音**：...
**画面**：（首帧→尾帧的画面变化描述）
**景别理由**：（为什么用这个景别）
**备注**：（与前后 shot 的衔接、动线参考来源、特殊要求）
```

## 状态流转

全流程统一使用一套状态值：

**项目级（分镜.md frontmatter）**：
```
草稿 → 脚本确认 → 分镜确认 → 制作中 → 完成
```

**Shot 级（提示词.md frontmatter + 分镜总览表）**：
```
待制作 → 参考确认 → 首帧确认 → 尾帧确认 → 视频确认
```

## 输出尺寸

| 平台 | 尺寸 | 比例 |
|------|------|------|
| 横版（B站/YouTube/官网） | 1920 × 1080 | 16:9 |
| 竖版（抖音/小红书/Reels） | 1080 × 1920 | 9:16 |
| 方形（社交媒体信息流） | 1080 × 1080 | 1:1 |

根据投放渠道在分镜.md 的 `format` 字段中指定。

字幕安全区：底部 60px，最大宽度 80%，字号 36px（1080p）。

生成分辨率：预览用 720p，成品用 1080p。
