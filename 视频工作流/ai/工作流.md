# 视频制作流程

本工作流严格门控：每个阶段必须获得用户明确确认后，才能进入下一阶段。

**核心框架：编剧→美术→摄影→后期。**

**分工原则：AI 负责创意（剧本、分镜、提示词），人负责生成工具操作和最终剪辑。**

---

## 阶段零：项目初始化

用户启动新项目时，先完成以下准备：

### 0a. 建目录

在 `项目/` 下创建项目目录和 `分镜.md`（按格式约定.md 模板）。

### 0b. 上传必要资产

用户需在项目初始化时提供以下资料，**所有资料必须在知识库中留痕**，否则中途断点或事后找补很难衔接：

| 资产 | 说明 | 存放位置 |
|------|------|----------|
| 风格锚点图 | 全片视觉风格的基准参考图 | 项目目录根 |
| 品牌素材 | logo、品牌色板、字体文件 | `素材/品牌/` 或项目目录 |
| 产品资料 | PRD、产品截图、核心功能说明等 | 项目目录根（如 `产品资料/`） |
| 已有参考 | 用户自己收藏的参考图/视频 | 对应 shot 的 `参考/` 目录 |

风格锚点图尤其重要——全片所有 shot 的生成都以它为风格基准，确保视觉统一。

### 0c. 确认资产完整

AI 检查以上资产是否齐全，缺什么提示用户补。不跳过。

---

## 阶段一：编剧（Script）

> 先不生成任何画面，先打磨剧本。故事不完整、平铺直叙是 AI 视频最常见的问题。

### 1a. 项目简报

用户提供（或 AI 引导确认）：

| 项目 | 说明 |
|------|------|
| 视频主题 | 做什么内容 |
| 目标时长 | 30s / 60s / 3min / 自定义 |
| 目标受众 | 给谁看 |
| 发布渠道 | 小红书/抖音/YouTube/官网等 → 决定画幅比例和节奏 |
| 视觉风格 | 写实/动漫/赛博朋克/手绘/3D 等 |
| 核心信息 | 必须传达的关键点 |
| 行动号召 | 看完之后希望用户做什么 |

### 1b. 故事脚本（多版方案）

**出 2-3 版脚本方案**，每版用不同叙事角度切入，标注各自的优劣：

| 维度 | 要求 |
|------|------|
| 叙事完整性 | 有起承转合，不是功能列表 |
| 价值融入 | 业务价值包在故事里，不是平铺直叙讲功能 |
| 代入感 | 观众能在前 3 秒产生"这说的是我"的感觉 |
| 情感弧线 | 有情绪起伏，不是一条直线 |

用户筛选并确认一版脚本。

### 1c. 叙事结构设计

根据视频类型选择叙事模板：

| 类型 | 结构 |
|------|------|
| 产品演示 | 钩子 → 痛点 → 方案展示 → 价值证明 → CTA |
| 品牌宣传 | 情感引入 → 品牌故事 → 愿景 → CTA |
| 故事短片 | 开场 → 发展 → 冲突/高潮 → 结局 |
| 广告 | 吸引 → 兴趣 → 欲望 → 行动（AIDA） |
| 教程/解说 | 问题 → 拆解 → 演示 → 总结 |

### 1d. 情绪曲线

设计整个视频的情绪走向，标注每个段落的情绪关键词。情绪曲线直接影响：
- 镜头节奏（快切 vs 慢推）
- 景别选择（特写=紧张聚焦，远景=释放开阔）
- BGM 风格（见音频规范.md）
- 参考选取方向

### 1e. 配音文案

逐段撰写配音文案（旁白/对白）。用文案字数估算时长（中文约 3-4 字/秒）。

> 注意：配音文案此时只用于估算时长和指导画面节奏，实际配音在后期阶段生成。

### ✅ 门控：用户确认剧本

用户确认故事脚本、叙事结构、情绪曲线、配音文案后，才进入阶段二。

---

## 阶段二：美术 + 摄影（Art Direction + Cinematography）

> 从剧本到可执行的逐镜头方案。一个 shot 一个 shot 过，不一次性全部生成。

### 2a. 分镜总览

先建立全局视角，在分镜.md 中完成：
- 拆分 shot 列表
- 每个 shot 标注：景别 + 景别的叙事理由 + 运镜 + 转场 + 情绪（景别选择参考镜头语言.md）
- 标注相邻 shot 的衔接关系

### 2b. 角色设定（如有真人角色）

进入分镜前先锁定角色（详见镜头语言.md 角色一致性章节）：
1. **四视图**（正面/侧面/3/4角度/背面，白底，统一光照）
2. **角色描述词**——后续所有 shot 复用同一段描述
3. **去假人化策略**

### 2c. 逐 Shot 制作

每个 shot 按以下流程推进：

**① 定调** — 明确叙事作用、景别+理由、运镜、与前后 shot 衔接（记录在分镜.md）

**② 搜参考** — 带着关键词搜索经典场面。静态参考管构图/色调/氛围，动态参考（视频片段）管动线/运镜。详见镜头语言.md 参考素材章节。

**③ 编写提示词** — 按格式约定.md 的提示词模板编写，记录在 shot 目录的提示词.md 中。

**④ 生成与迭代（"一笔笔画"）** — 不指望一次出成品：
1. 生成首帧 → 用户确认
2. 生成尾帧 → 用户确认（注意与下一 shot 衔接）
3. 生成视频 → 用户确认
4. 不满意 → 调整提示词或更换参考图 → 重新生成

**⑤ 多模态输入** — 视频生成模型支持同时喂入图片（锁角色/构图）、视频（锁动线/运镜）、音频（驱动口型）、文字（串联意图）。通过直接喂素材跳出"抽卡式"盲目生成。

**⑥ 质量自检** — 角色一致性（对比四视图）、风格统一性（对比风格锚点图）、动作自然度、去假人化。

### ✅ 门控：用户确认当前 shot 的首帧、尾帧、视频

确认后进入下一个 shot，重复以上流程。

---

## 阶段三：后期与交付

所有 shot 画面确认后，进入后期：

1. **配音生成** — 用 TTS 逐镜头生成配音（或人工录制），按实际配音时长微调剪辑节奏
2. **字幕生成** — AI 自动生成字幕，人工校对
3. **BGM** — 按总时长 + 情绪曲线生成或选取 BGM
4. **变速处理** — 关键动作减速、过渡段加速（详见镜头语言.md 变速处理）
5. **画质修复** — 修复 AI 视频瑕疵、提升分辨率
6. **品牌植入** — 统一人物、统一材质、优雅的品牌露出
7. **最终合成** — 人拿着素材去剪映/Premiere/FCP 完成剪辑
8. **多语言/多平台** — 同一内容可快速适配不同语言和平台比例

### ✅ 门控：用户确认最终成品

## 关键原则

| 原则 | 说明 |
|------|------|
| 资产先行 | 风格锚点、产品资料、品牌素材必须在项目初始化时上传，全程留痕 |
| 先剧本后画面 | 故事打磨好了再动手生成，不要跳步 |
| 编剧→美术→摄影 | 三个角色缺一不可 |
| 多版方案筛选 | 脚本阶段出多版，选最好的 |
| 价值融入叙事 | 把业务价值包在故事里，不平铺直叙 |
| 景别有叙事目的 | 每个景别都在传递特定信息，不是随便选 |
| 逐 shot 推进 | 一个一个过，不批量生成 |
| 一笔笔画 | 不指望一次到位，渐进式构建 |
| 参考驱动 | 名场面截帧管构图/色调，真实视频管动线 |
| 提示词必须留存 | 写进 shot 目录的提示词.md |
| 配音后期处理 | 画面先行，配音在后期阶段匹配 |
| 精准修改 | 只改指定的 shot，不扩大范围 |
| 人负责剪辑 | AI 交付素材，最终合成由人完成 |

## 常见问题自检

| 问题 | 对应角色 | 解决方向 |
|------|----------|----------|
| 故事不完整，没有代入感 | 编剧 | 回到剧本阶段，补叙事弧线 |
| 平铺直叙，无法打动用户 | 编剧 | 把功能点包进故事，不要列清单 |
| 假人感太重 | 美术 | 去假人化提示词 + Higgsfield |
| 服化道不统一 | 美术 | 角色四视图 + 描述词锁定 |
| 风格不统一 | 美术 | 回到风格锚点图对比，每个 shot 对齐 |
| 没有镜头逻辑 | 摄影 | 每个景别标注叙事理由 |
| 节奏混乱 | 摄影 | 变速处理 + 情绪曲线对照 |
| 缺乏情感渲染 | 摄影 | 微表情、虚实切换、BGM 配合 |
| 像 PPT 在动 | 摄影 | 景别切换 + 运镜 + 变速 |
