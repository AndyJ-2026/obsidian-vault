# Meeting CLI 使用指南

会议纪要工具。开会时打开，自动录音转文字，结束后自动生成结构化纪要。

还没装？先看 [[Meeting CLI 安装指南]]。

---

## 基本用法

每次开会三步：

### 1. 打开终端

按 `Command + 空格`，输入"终端"，回车。

### 2. 开始录音

先进入工具目录：

```
cd ~/meeting-cli
```

然后根据场景选命令：

| 场景               | 命令                                            |
| ---------------- | --------------------------------------------- |
| 面对面会议（录麦克风+电脑声音） | `./meeting.sh start`                          |
| 线上会议（只录电脑声音，推荐）  | `./meeting.sh start --system-only`            |
| 线上会议 + 后台有其他声音   | `./meeting.sh start --system-only --app Lark` |
| 不确定应用叫什么名字       | `./meeting.sh start --list-apps`              |

看到"会议录音+转写 已开始"就成功了，屏幕会实时显示转写文字。

> `--app` 后面跟应用名称，只采集那一个应用的声音。电脑静音也不影响录制。

常见应用名：

| 应用                   | `--app` 参数     |
| -------------------- | -------------- |
| 飞书会议                 | `--app 飞书会议`   |
| 飞书视频/音频              | `--app 飞书`     |
| Lark                 | `--app Lark`   |
| Zoom                 | `--app Zoom`   |
| 腾讯会议                 | `--app 腾讯会议`   |
| Chrome (Google Meet) | `--app Chrome` |

### 3. 结束会议

按 `Ctrl + C`（按住 Control 再按 C），工具自动：

1. 停止录音
2. AI 生成结构化纪要
3. 保存到 Obsidian「会议纪要」文件夹（文件名如 `2026-04-19 会议纪要.md`）
4. 问你要不要上传飞书 — 输 `y` 回车上传，直接回车跳过

## 嘈杂环境处理

### 调高噪音过滤

适合面对面会议、周围有人说话的情况：

```
cd ~/meeting-cli
MEETING_SPEECH_THRESHOLD=0.015 ./meeting.sh start
```

数字越大过滤越强。默认 0.005，嘈杂环境用 0.015，还有杂音试 0.02。太高会把小声说话也过滤掉。

设为永久：

```
echo 'export MEETING_SPEECH_THRESHOLD=0.015' >> ~/.zshrc
```

关掉终端重新打开即生效。

### 只录电脑声音

线上会议推荐。完全不用麦克风，周围再吵也不影响：

```
./meeting.sh start --system-only
```

电脑音量调 0、点静音都不影响录制。系统声音在到喇叭之前就被抓取了。

所以你可以：静音挂机录会议、开放工位不打扰别人、不想听只想看纪要。

### 只录某个应用

后台开了多个有声音的东西时用：

```
./meeting.sh start --system-only --app 飞书会议
```

只录指定应用，其他声音不会被采集。

## 自定义纪要格式

打开 Obsidian，编辑「会议纪要」文件夹里的 [[纪要模板]]。你写什么格式，AI 就按什么格式生成。

可以改成：只要待办事项、按项目分类、加风险提示章节、用英文输出……

改完保存即生效。改坏了删掉 `纪要模板.md`，自动恢复内置默认模板。

## 常见问题

**纪要存在哪？**
Obsidian →「会议纪要」文件夹，文件名是日期。

**能重新生成纪要吗？**
不能，转写文件生成纪要后自动清理。不满意可以手动编辑纪要。

**终端关了/电脑息屏了？**
录音会中断。开会期间保持终端开着、电脑不合盖。
